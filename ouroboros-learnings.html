Day 1 Config Module & Git Fundamentals

@dataclass

Auto-generates __init__, __repr__, comparisons. Convenient, not required.

__all__ exports

Declares public API in __init__.py. Controls what * imports.

Git Three States

Working dir → Staging → Repository. You control what goes in each commit.

Mutable Default Gotcha

dict = {} as class default → all instances share SAME dict. Use field(default_factory=lambda: {...}) instead.

from dataclasses import dataclass, field

@dataclass
class Config:
    name: str = "default"
    options: dict = field(default_factory=lambda: {}) # Fresh dict each time!
"Config module is like an ODN junction - centralized data flow. Everything routes through one place."

Day 2 Environment Variables & Data Generator

Environment Variables

Runtime config without code changes. Set via inline, export, .env, or CI/CD.

Pure Functions

Input → output, no side effects. Easier to test, easier to reason about.

Dependency Injection

Pass dependencies in (like session), don't create them inside. Enables testing with mocks.

Virtual Environments

Isolate deps per project. python3 -m venv .venv then use .venv/bin/python.

import os

def env_or_default(key, default):
    """Read from env, fall back to default."""
    return os.environ.get(key, default)

# Usage: ML_TIMEOUT=300 python script.py

Filter Pipeline

Chain filters: all → row_limits → exclude_tested → cap. Each step is a pure function.
